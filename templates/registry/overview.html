메타데이터 관리 프로세스

최초 설정 후 등록·점검·보완을 반복합니다.
  1. 1

    관리 기준 설정

    기업명·사업기간을 입력하고, 사업에서 요구하는 추가 메타데이터 항목을 설정합니다.

    결과 · 기업·사업 정보와 관리항목
    사용 메뉴{% if user.is_staff %}사업·항목 설정{% else %}사업·항목 설정관리자 담당{% endif %}
  2. 2

    데이터셋 등록

    공정·설비별 데이터 이름, 설명, 담당자를 등록합니다. 기존 대장은 표준 Excel 양식으로 가져올 수 있습니다.

    결과 · 데이터 목록과 고유 관리번호
    사용 메뉴데이터 목록{% if user.is_staff %}Excel 가져오기{% endif %}
  3. 3

    데이터 정의 작성

    수집 출처·방법·주기, 저장 위치, 권리·이용조건을 작성하고 컬럼의 의미·자료형·단위를 정의합니다.

    결과 · 데이터 정의 및 컬럼 정의
    사용 메뉴데이터 목록데이터 선택 → 상세·편집
  4. 4

    점검 및 보완

    필수항목 누락과 관리현황을 확인합니다. 담당자·DX멘토단의 점검 의견을 기록하고 조치 내용과 증빙을 보완합니다.

    결과 · 점검 기록, 조치 내용, 증빙
    사용 메뉴점검·제출기록·조치는 데이터 상세에서 입력
  5. 5

    제출자료 생성·보관

    제출할 데이터셋을 선택해 Excel을 생성합니다. 생성 당시 내용은 보존되며, 이후 원본을 수정해도 기존 제출본은 유지됩니다.

    결과 · 데이터 정의·관리현황 Excel과 제출본
    사용 메뉴점검·제출제출본 생성 및 다운로드
