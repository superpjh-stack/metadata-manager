# 제조데이터 메타데이터 관리 시스템 구현 계획

사용자가 승인한 메타프롬프트 실행. 단일 기업·사업의 등록 → 정의 → 점검 → 제출 업무를 로컬 Django 앱으로 구현한다. 공식 서식·법적 적합성·실제 자동 수집·AAS 연계를 주장하지 않는다.

## 루프와 완료 기준
1. 기반·등록: 로그인, 권한, 데이터 영속성, 3개 주요 화면.
2. 정의·점검: 컬럼 고유성, 필수항목 계산, 점검 이력과 조치 검증.
3. 확장·증빙: 동적 추가 항목, 인증된 첨부, 변경 전후 이력.
4. 가져오기·제출: 표준 양식 검증/미리보기/원자적 신규 저장, 변경 불가능한 제출본.
5. 검증·인계: 핵심 자동 테스트, 브라우저 흐름, 샘플 Excel, 백업 복구 시험, README.

## 설계
Django 서버 렌더링 + SQLite + openpyxl. 사용자 is_staff를 관리자 역할로 사용하고 조회자는 읽기만 허용한다. 파일은 인증된 뷰로만 제공한다. 제출본 스냅샷과 Excel 바이트를 동일 DB 레코드에 함께 저장하여 원자성을 확보한다. 추후 공식 요구는 추가 항목 또는 명시적 코드 변경으로 반영한다.

## 제한
로컬 개발 서버만 실행한다. 운영 배포·인증서·외부 수집 연동은 범위 밖이다. 표준 Excel 가져오기는 신규 등록만 지원한다. 브라우저에서 동시 편집 시에는 수정 시각을 비교해 덮어쓰기를 방지한다.
