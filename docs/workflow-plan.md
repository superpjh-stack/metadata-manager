# 내 업무·정기 확인·보완 조치

- 내 업무: 로그인 기본 화면. 일반 사용자는 배정 데이터의 확인 및 배정 조치만 표시. 관리자는 전체/내 업무 전환. 기한 경과, 검토 대기 우선.
- 정기 확인: 기본 30일, 7/30/90일 또는 수시(0). 최초 기한은 설정값 또는 등록일. 데이터 수정 후에는 재확인 필요. 세 항목을 직접 확인한 뒤 변경 없음 기록. 변경 필요 기록은 메모 필수이며 완료로 간주하지 않는다. 담당자 및 관리자만 기록한다. 마지막 확인일과 수정일 구분.
- 보완: 실제 조치 담당자와 완료 기한. 담당자는 조치 중/검토 요청만 가능. 관리자가 완료 확정 또는 반려(보완 중). 기존 완료 기록은 그대로 보존. 미지정/기한 미설정은 관리자 화면에서 표시.
- 명시적 업무 권한: 기존 조회 계정이라도 배정된 확인과 조치는 처리 가능. 데이터 정의·담당자·기한·다른 사람의 조치·완료 확정은 관리자 전용. 증빙은 배정 데이터 담당자 또는 열린 조치 담당자가 해당 데이터에 첨부 가능.
- 이력: 현황 확인 별도 누적 저장, 조치 변경 감사 로그, 새 제출본에 확인/기한/계정 스냅샷 보관. 기존 제출본 불변.
- 검증: 기한 경계, 수정 후 재확인, 실제 처리 권한/완료 우회 차단, stale form·중복 확인 방지, 미지정 집계, 과거 이력 및 제출본 보존. 운영 백업 후 additive migration 배포.
