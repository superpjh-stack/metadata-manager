# 구현 및 검증 기록

검증일: 2026-11-25 (Asia/Seoul)

## 루프 결과

1. 기반: 빈 폴더에 Django·SQLite 앱 구성. 모델, 마이그레이션, 인증, 관리자/조회자 권한 구현. Django system check 통과.
2. 정의·점검: 데이터셋·컬럼 CRUD, 누락 계산, 점검/조치, 추가 항목, 첨부, 변경 이력 구현. 데이터셋 수정 시각 비교로 오래된 편집 저장을 차단.
3. 가져오기·제출: 표준 양식, 전체 검증, 미리보기, 일회성 확정, 트랜잭션 저장 구현. 스냅샷과 Excel 바이트를 같은 DB 레코드에 저장.
4. 검증·수정: 핵심 테스트 20개 통과 후 리뷰에서 존재하지 않는 제출 대상의 500 오류 가능성을 찾아 사용자 오류 메시지로 수정. 기본 필수 메타데이터의 화면 표시 개선. 회귀 테스트 5개 추가.
5. 인계: 실제 HTTP 업무 흐름 검증, DB·증빙 백업 복구 시험, 실행 스크립트와 README 작성.

## 실제 HTTP 검증

가상 예시 서버에서 표준 라이브러리 HTTP 클라이언트로 요청. Django 테스트 클라이언트가 아닌 실제 HTTP이며 CSRF 검사를 활성화한 상태.

- 비밀번호 로그인 성공
- 목록·상세·편집·제출·설정·가져오기 응답 확인
- multipart CSV 증빙 업로드 성공
- 인증된 증빙 다운로드 바이트 확인
- POST 제출본 생성 성공
- XLSX 다운로드 확인

## 백업 복구

서버를 중지하고 `scripts/verify_backup.py` 실행.

- SQLite backup API로 DB 백업
- 증빙 파일 및 SHA-256 manifest 포함
- 임시 새 디렉터리에 복구
- 데이터셋·컬럼·점검·첨부·제출본·변경 이력·계정 테이블의 모든 행 비교 일치
- 제출본 BinaryField 바이트도 동일하게 보존
- 증빙 파일 SHA-256 일치
- 복구 DB/MEDIA_ROOT를 사용하는 별도 프로세스의 Django system check 통과

## 미검증 및 미설정

- 브라우저 제어 도구가 `The browser access host is unavailable`을 반환하여 실제 브라우저 화면·모바일 레이아웃·JavaScript 컬럼 추가 버튼의 시각/상호작용 검증은 미수행.
- Excel 앱에서 전체 시트의 시각 검증 미수행. openpyxl 재개방으로 구조·값·셀 자료형·서식 속성은 검사함.
- 운영 배포·HTTPS·정기 백업 작업 등록은 미수행. 설정 절차만 제공함.
- 실제 제조데이터 수집, 공식 서식 대조, AAS 적합성 검증은 범위 밖.

따라서 핵심 서버 기능 구현과 자동/HTTP/복구 검증은 완료했으며, 시각 검증과 운영 환경 검증은 별도로 남아 있다.

## UI 개선 후 추가 검증

2026-11-25: 공통 UI를 밝은 사이드바·블루 액션·네이비 개요 영역으로 개선. 공통 CSS 정리, 메뉴 활성 표시와 경로 안내, 모바일 메뉴, 키보드 포커스 및 reduced-motion 대응 추가.

- 기존 회귀 테스트 25개 다시 통과.
- 브라우저 탭 제어 호스트는 연결 불가했으나 네이티브 Chrome 앱 제어로 시각 검증 수행.
- 좁은 창에서 목록·개요 화면, 메뉴 펼침 및 개요 이동 확인.
- 넓은 창에서 개요 상단, 관리 프로세스, 데이터 목록의 배치 확인.
- 줄바꿈이 숨겨질 때 문장이 붙는 문제 및 낮은 창에서 사이드바 스크롤이 생기는 부분 수정.
- 모든 페이지/기기의 시각 검증이나 Excel 앱 시각 검증까지 완료한 것은 아님.
